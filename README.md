## Асинхронный чат

  

Ассинхронный чат на Python, использующий современные возможности asyncio

  
  

#### Как установить #

  

Для использования должен быть установлен Python 3+. Для установки зависимостей используйте: <br>  
`pip install -r requirements.txt`  <br>

Для запуска приложения: python main.py. Предусмотрены необязательные параметры, которые можно посмотреть командой:
 <br>  `python main.py -h`

 #### Регистрация #



 Для регистрации (получение токена) в чат клиенте необходимо прописать python gui_regi.py. В открывшемся придумать и ввести nickname, далее нажать кнопку "Отправить". После чего откроется информационное окно с вашем именем и токеном.

  
  

#### Цель проекта #

  

Изучить ассинхронное проргаммирование и сокеты на примере чата.
