## Асинхронный чат##

Ассинхронный чат на Python, использующий современные возможности asyncio

***

#### Как установить # 

Для использования должен быть установлен Python 3+. Для установки зависимостей используйте: \pip install -r requirements.txt\  
Для запуска приложения: python main.py -m <Любое сообщение>. Помимо обязательного параметра (-m) есть еще и необязательные, которые можно посмотреть командой: \python main.py -h\


#### Цель проекта # 

Изучить ассинхронное проргаммирование и сокеты на примере чата.
